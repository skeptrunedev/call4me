# Additional Postiz publisher prospects

October 5, 2026. Six additional candidates for Call4me, beyond the nine
publishers already emailed. Reviewed twelve more publishers from the existing
Ahrefs sample. This continues the partial sample described in the
[first campaign report](./postiz-backlink-outreach-2026-10-05.md).

## Verification

Each shortlisted publisher currently links to Postiz. The exact live links
have neither `nofollow` nor `sponsored`. Contacts come from primary public
pages, with no guessed addresses. Ahrefs domain ratings are snapshot metrics,
not observed audience sizes or predicted ranking gains.

Checked the fresh 158 record outreach tracker by domain, published email and
verified names. A separate connected mailbox search found no messages to or
from the six selected public addresses. None of these prospects was contacted,
added to the tracker or given a mailbox draft during the initial research.

Only Mailmodo publishes an explicit content collaboration program. An existing
Postiz link does not establish that a publisher accepts reciprocal links.
All placements below are proposals. Combined product workflows have not been
tested and no return citation is promised.

## Specific placements and possible return resources

### Pinggy

Its [self hosted app guide](https://pinggy.io/blog/best_self_hosted_apps/)
contains the Postiz links. A better requested placement is the MCP Server
Support section of its
[Claude Code and Codex mobile workflow](https://pinggy.io/blog/remotely_manage_claude_code_from_phone/),
pointing to our [Claude Code calling guide](https://call4.me/blog/claude-code-phone-calls).
The mobile workflow is a possible related resource for readers who want to
monitor their existing coding session away from a desk. Remote control of a
session and letting an agent call a business are separate capabilities.
The contact is a company inbox, not a verified personal editor address.

### Mailmodo

Its [AI marketing agent guide](https://www.mailmodo.com/guides/ai-marketing-agent/)
links to a Postiz founder case study. Tool selection and agent evaluation are
better contexts for our
[recorded research workflow](https://call4.me/blog/agent-web-research-phone-calls-sf-private-dining).
Its [marketing partner program](https://www.mailmodo.com/marketing-partner/)
invites joint blogs and guides. A joint practical article is a stronger fit
than adding a reciprocal citation without new useful context. The public
contact page explicitly assigns its enquiries address to partnerships.

[Claude Code MCP setup section](https://postory.io/blog/claude-twitter-mcp#connect-x-to-claude-code-from-the-terminal)

That same Postory setup article is a possible related resource for another
