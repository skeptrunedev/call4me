An **Aquasana return exception request** needs a clear account of the item, why the ordinary return window does not cover it and what outcome you are asking customer service to approve. It also needs a practical finish: return instructions, the approved amount, the refund method and the next step.

On October 6, 2026, a call4me customer's AI assistant called Aquasana about an unopened filter that was past the 90 day return window discussed on the call. The caller explained that package forwarding after a move had delayed receipt and asked for an exception.

After checking with another department, the representative said the return was approved and quoted **$551.79, to be refunded by check**. **The recording establishes approval, not a completed refund.** Return instructions and an authorization code were still to be sent, and the call did not provide an RMA, shipping label or return address.

## Approval left several steps unfinished

The caller stayed on the line instead of accepting the automated callback offer. A customer service representative answered, but the requested supervisor was unavailable. The representative consulted another department and returned with the approval. Order processing, rather than a supervisor reached on the call, was to handle the return.

Staff said the return would need to be started manually, with instructions and an authorization code sent afterward. They described up to 15 business days for processing and mailing the check and said tracking might allow processing to start sooner. The conversation did not establish a calendar date on which payment would arrive.

The assistant also asked about two previously discussed filter returns. Staff confirmed **$38.55 for a sediment filter**, but did not confirm a separate post filter amount. Combining those questions into a claim that every refund was resolved would lose an important limit of the call.

These are the answers given in this individual case. They do not establish Aquasana's current return policy or guarantee an exception for another order.

## What to ask before ending a return call

1. Has the exception actually been approved, and for which item?
2. What exact amount and payment method are authorized?
3. Who will send the return instructions and authorization code?
4. Are a shipping label and destination available now or still pending?
5. What event starts the refund process, and what timing can staff confirm?
6. What case reference should you use if the next step does not arrive?

Keep unresolved items in the result. A case number and an approval are useful progress, but they do not prove that a package was returned or money was received.
