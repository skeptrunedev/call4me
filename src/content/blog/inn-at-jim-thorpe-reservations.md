## Asking about Inn at Jim Thorpe prices by phone

The brief did two useful things. It named backup weekends up front, so when October 23 to 25 came back sold out, the assistant asked about both alternatives in the same breath instead of hanging up. And it set an all in budget, which let the assistant say plainly that $649.64 was over it, while still getting the price "for comparison".

What it would have done better: ask about one weekend at a time. Bundling both meant the answer didn't say which weekend the West Broadway room was for. If staying in the main inn matters to you, say so: the West Broadway building has no elevator, front desk or restaurant, which the front desk mentioned before the price.
